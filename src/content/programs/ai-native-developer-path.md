## What This Covers

A major pathway for developers building software with AI as a core part of the workflow, not a side tool:

- AI coding for absolute beginners and vibe coding fundamentals
- AI-assisted software development, spec-driven development, and coding agents
- AI-assisted debugging, AI-assisted testing, and Git/GitHub with AI
- AI code review & refactoring, and repository-level agentic development
- Building full applications with AI, and an AI-native SDLC
- Security & responsible vibe coding
- An AI-Native Developer capstone project

Technology labs cover specific tools — Claude, Codex, Cursor, GitHub Copilot, and future coding agents — without tying the pathway itself to any one brand.

## Who This Is For

Developers who want a structured, self-paced path into AI-native development rather than picking up coding-agent habits ad hoc.
