## About this program

Become the engineer who can take a real business problem and deliver a working AI solution. The program combines a 7-week live engineering intensive with 6 months of fortnightly project mentorship for experienced software professionals.

Eight or more years of experience is the suggested audience, not a strict requirement. Strong engineers with fewer years are welcome when they have solid programming and software engineering fundamentals.

## One Program. Two Phases.

### Phase 1 - 7-Week Live Engineering Intensive

Across 28 live sessions, build LLM applications, enterprise RAG, controlled agents, evaluation systems, and a production deployment. The intensive includes 42 hours of instructor-led training plus optional Saturday office hours.

### Phase 2 - 6-Month Project Implementation Mentorship

From January through June 2027, work through three progressively challenging enterprise projects with fortnightly implementation clinics, architecture discussions, code feedback, and iterative improvement.

## Complete Curriculum: 7 Weeks, 28 Live Sessions

### Week 1 - FDE Foundations & AI Solution Design

- Forward Deployed Engineering: discovery, stakeholder interviews, success metrics, and when AI is the wrong solution
- LLM Engineering Essentials: models, context, prompt engineering, selection, latency, and cost
- Building AI Services: Python, FastAPI, Pydantic, OpenAI API, structured outputs, and streaming
- Solution Architecture Workshop: requirements, architecture diagrams, tool calling, and service integration

Build: An API-backed AI service with typed responses and a customer requirement brief.

### Week 2 - LangChain & LLM Application Engineering

- LangChain fundamentals, structured generation, and direct SDK trade-offs
- Tools, function calling, schemas, validation, retries, and external APIs
- Context management, model routing, fallback, rate limits, and cost control
- Enterprise integration with databases, REST APIs, authentication boundaries, and tests

Build: A tool-enabled enterprise AI assistant connected to simulated business APIs.

### Week 3 - Enterprise RAG & Knowledge Systems

- RAG architecture, ingestion, parsing, chunking, embeddings, and similarity search
- PostgreSQL, pgvector, metadata filtering, tenant isolation, and hybrid retrieval
- Query rewriting, reranking, context assembly, citations, and retrieval failure modes
- Evaluation datasets, relevance, groundedness, tracing, and debugging with LangSmith

Build: An evaluated enterprise knowledge assistant with document retrieval and source attribution.

### Week 4 - Agentic AI, LangGraph & MCP

- Agent architecture, execution boundaries, and when not to use an agent
- LangGraph state, persistence, recovery, and human approvals
- MCP clients, servers, authentication, permissions, and tool safety
- OpenAI Agents SDK agents, tools, handoffs, guardrails, tracing, and architecture trade-offs

Build: A stateful enterprise agent with MCP tools and human approval for sensitive actions.

### Week 5 - Evaluation, Testing, Security & Reliability

- Golden datasets, deterministic checks, LLM-as-judge limitations, and quality metrics
- LangSmith tracing, dataset experiments, and regression testing
- Prompt injection, data leakage, access control, least privilege, and tool safety
- Timeouts, retries, circuit breakers, idempotency, fallbacks, and incident scenarios

Build: An automated evaluation and regression suite, security tests, and an operational failure-handling plan.

### Week 6 - Docker, GitHub Actions & AWS Production AI

- Docker images, containers, configuration, secrets, and local integration testing
- GitHub Actions, automated tests, evaluation gates, and deployment pipelines
- AWS ECS Fargate, IAM, Secrets Manager, verification, and rollback
- CloudWatch and LangSmith observability for latency, quality, throughput, tokens, and cost

Build: A Dockerized AI application deployed on AWS through a GitHub Actions pipeline.

### Week 7 - FDE Capstone & Customer Delivery

- Customer requirements, acceptance criteria, assumptions, scope, and delivery risk
- Architecture and implementation review across models, retrieval, agents, security, and scale
- Production readiness, monitoring, runbooks, release criteria, documentation, and handover
- Customer-facing demonstration, architecture defense, feedback, and implementation roadmap

Build: A deployed AI solution with architecture documentation, evaluation results, and a technical demonstration.

## Six-Month Mentorship Projects

### Enterprise Knowledge AI

Design and implement an enterprise knowledge system with ingestion, retrieval, access controls, evaluations, and operational tracing.

### IT Operations AI Agent

Build an agent that investigates incidents, interacts with operational tools, and proposes actions with human approval.

### Customer-Facing AI Solution

Respond to an ambiguous customer brief, handle changing requirements, and deliver an evaluated, deployed solution.

## Frequently Asked Questions

### Is 8+ years of experience mandatory?

No. Eight or more years is the suggested audience. Engineers with less experience can join if they have strong coding skills and software engineering fundamentals.

### Do I need prior AI or ML experience?

Deep AI or ML experience is not required. You should already be comfortable with programming, APIs, debugging, and application development. The course is not intended for programming beginners.

### What programming language will be used?

Python is the common implementation language. Experience in Java, C#, TypeScript, C++, Kotlin, or another established language is a suitable starting point, but you must be prepared to write Python during the program.

### Will we learn LangChain, LangGraph, and OpenAI Agents SDK?

Yes. LangChain, LangGraph, LangSmith, and OpenAI Agents SDK are part of the core path, taught through engineering use cases, implementation patterns, and trade-offs.

### Will Docker, AWS, and CI/CD be covered?

Yes. The core deployment path uses Docker, GitHub Actions, and AWS ECS Fargate, with monitoring and secrets management. Kubernetes and advanced MLOps are optional extensions during mentorship.

### What happens during the six-month mentorship?

You will work on progressively challenging enterprise AI projects with fortnightly implementation clinics, architecture discussions, code feedback, and iterative improvements.

### How much time should I commit?

The intensive has six hours of core classes each week plus optional Saturday office hours. Plan for approximately 3-5 additional hours of independent practice and assignments, followed by consistent project work during mentorship.

### What if I miss a live class?

Session recordings are included to help you catch up. Live attendance is strongly recommended for hands-on implementation, discussions, and feedback.

### Are cloud or model API charges included?

Some exercises may require paid model APIs or cloud services. Those charges are separate unless explicitly included in the registration offer, and cost-controlled configurations will be preferred.

### Where can I see the fee?

The current fee and registration details are available on the linked registration page.
