## What This Covers

The common core every GenAI builder follows, regardless of which career path comes next:

- **Prompt engineering** — prompt anatomy, zero-shot and few-shot patterns, prompt templates, and testing
- **Context engineering** — assembling instructions, history, retrieved data, tool results, memory, and state into effective context, including token budgeting and compression
- **Structured outputs & data extraction** — schemas, typed outputs, validation, and failure handling
- **Embeddings & semantic search** — vector intuition, similarity, and search quality
- **Vector databases & retrieval engineering** — indexing, hybrid retrieval, and reranking
- **RAG fundamentals** — ingestion, chunking, retrieval, context assembly, citations, and basic evaluation
- **AI workflows & automation** — triggers, actions, conditions, and human-approval steps
- **Tool & function calling** — how an LLM selects and uses tools, kept explicitly separate from agents
- **AI agent fundamentals** — the agent loop, planning, memory, and agentic RAG

Completing this track earns the GenAI Builder milestone and opens the door to a career specialization.

## Who This Is For

Developers and technical professionals ready to build real GenAI applications, coming from AI & GenAI Foundations or equivalent experience.
