## Who This Is For

This workshop respects the experience you already have. You may come from Java, .NET, C++, Python, platform engineering, cloud, DevOps, architecture, or technical consulting. You are not starting your career again — you are extending your engineering experience into agentic AI. You do not need deep machine-learning knowledge, but you should be comfortable with programming concepts, APIs, and following a guided coding session.

It's built for senior software engineers and tech leads, backend and platform engineers, solution and application architects, technically involved engineering managers, cloud/infra/DevOps professionals with coding exposure, and technical consultants exploring agentic AI.

## What We Will Build Together

A practical multi-agent system that receives a task, plans the work, calls tools, shares context, and produces a useful final result: a user request enters the system, an orchestrator understands the goal and routes work, specialist agents plan/research/execute subtasks, agents call tools and external capabilities, shared state and memory carry context through the workflow, and a useful, traceable final response is produced.

The objective is not to memorise a framework. It is to understand the system architecture well enough to explain why each component exists.

## Your 3-Hour Build Plan

**Part 1 — Architecture First.** Understand the problem, agent roles, orchestration flow, tools, memory, and expected output.

**Part 2 — Build Together.** Create the agents, wire the workflow, connect tools, and run the system step by step.

**Part 3 — Debug and Improve.** Inspect failures, improve instructions, and understand where engineering discipline matters.

**Part 4 — Your Extension Roadmap.** See how to evolve the mini-build into a portfolio project or a workplace-relevant AI use case.

## What You Will Understand by the End

- How an AI agent differs from a normal LLM call or chatbot
- How prompts, tools, state, memory, and orchestration fit together
- When a single agent is enough — and when multi-agent design is justified
- How to structure a controlled agent workflow instead of creating an unpredictable demo
- Where failures happen and how software engineering practices still apply
- How to extend the starter system into a stronger portfolio or workplace use case

## What You Will Leave With

**A working system:** a functioning multi-agent workflow that can reason through a task, call tools, and produce a useful result.

**Architecture clarity:** a clear mental model of how the major building blocks connect, without drowning in framework jargon.

**Confidence to continue:** starter code, an extension roadmap, and proof that GenAI is something you can build — not merely consume.

The real outcome is not "I attended an AI workshop." It is "I built an agentic system, and I can explain how it works."

## Check Whether This Workshop Fits You

**Join if:** you have professional software, cloud, infra, or technical consulting experience, understand basic programming and APIs, want to build your first agentic AI system with guidance, can follow a live coding session and try the steps yourself, and want clarity and confidence rather than another broad overview.

**Do not join if:** you want only a non-technical AI awareness session, have no programming exposure at all, expect to master production agentic AI in three hours, want to watch passively without opening the code, or are joining only to collect a certificate.

## Frequently Asked Questions

### Do I need previous GenAI or machine-learning experience?

No deep AI or ML background is required. The session starts with the system architecture and connects it to programming, APIs, and workflow concepts you may already know.

### Do I need to be a Python expert?

No. You should understand programming and be comfortable following guided code. Experienced Java, .NET, C++, Go, and other developers should be able to follow the Python used in the workshop.

### Will I build during the session?

Yes. This is a Build Together Live session. You will receive starter code and follow the implementation, run the workflow, and make guided changes during the workshop.

### What should I have ready before the workshop?

A laptop, a stable internet connection, and the development setup shared in the pre-workshop instructions. Complete the setup before the session so the live time can be used for building.

### Will recordings be available?

Live attendance is strongly encouraged because the hands-on flow, debugging, and Q&A are central to the experience. A recording with lifetime access will be shared though.

### Will I become production-ready in three hours?

No honest workshop should promise that. You will gain a working first system, a clear architecture model, and a roadmap for progressing toward production-grade AI Engineering.

### Is this suitable for non-technical business leaders?

This version is designed primarily for professionals who can follow code and understand software or technical systems. A non-technical AI leadership session would need a different format.

### What happens after the workshop?

You will receive an extension roadmap showing how the mini-build can grow into a more robust project. Professionals who want a deeper transition can also explore the longer AI Engineering mentorship path.
